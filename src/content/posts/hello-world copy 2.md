这是这个博客的第一篇笔记。

## 为什么写博客

写下来，才算发生过。想法在脑子里的时候总是完整又漂亮，一旦落到文字上，才会暴露出那些没想清楚的地方。

## 这里会写什么

- 技术笔记 —— 踩过的坑、解决问题的过程
- 阅读记录 —— 读完一本书之后还能想起来的部分
- 生活杂记 —— 值得留下的碎片

## 代码也能正常显示

```js
const greet = (name) => {
  return `你好，${name}`;
};

console.log(greet("世界"));
```
